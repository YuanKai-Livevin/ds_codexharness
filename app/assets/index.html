导入 SKILL

一个 SKILL 就是一个文件夹，内含 SKILL.md 文件：

skill-name/
└── SKILL.md

SKILL.md 格式（YAML frontmatter 声明 name 与 description）：

---
name: skill-name
description: 一句话描述技能用途
---
# 技能说明与执行步骤

两种导入方式：

  • 选择文件夹：选择包含技能文件夹的目录，应用会自动复制到技能仓库；
  • 手动放置：直接把技能文件夹放到 %APPDATA%\OfficeHarness\skills 目录。
